# Week 3 — AI/ML Internship

This repository contains my work for Week 3 of the AI/ML Internship.

## Tasks Completed

### Task 3.1 — TensorFlow/Keras
Built and trained a neural network using TensorFlow/Keras and compared its performance with a previous PyTorch model.

### Task 3.2 — Computer Vision
Built a Convolutional Neural Network (CNN) using TensorFlow/Keras and the CIFAR-10 dataset.

- Dataset preparation and preprocessing
- CNN model building and training
- Model evaluation
- Image prediction
- Saved trained model
- Test accuracy: **67.37%**

### Task 3.3 — Prompt Engineering
Designed, tested, and improved prompts for:

- Reasoning
- Information Extraction
- Summarization
- Coding

The prompts were evaluated by comparing initial and improved versions.

### Task 3.4 — AI-Assisted Coding
Built a small Gradio application for CIFAR-10 image classification using the trained TensorFlow/Keras model.

The generated code was reviewed and improved, including image preprocessing and RGB conversion.
